# Umar Hussain — Portfolio Website

This is the complete GitHub Pages version of my portfolio. The HTML, CSS and JavaScript are kept in separate files, with images and videos organised inside the `assets` folder.

## Project structure

```text
Umar-Hussain-Portfolio-GitHub/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
    ├── favicon.svg
    ├── images/
    └── videos/
```

## Publish with GitHub Pages

1. Create a GitHub repository for the portfolio.
2. Upload everything in this folder to the root of the repository. Keep the `assets`, `images` and `videos` folder structure unchanged.
3. Open the repository's **Settings**.
4. Select **Pages** from the left-hand menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/(root)` folder, then save.
7. GitHub will provide the published website address after the deployment completes.

If the repository is called `portfolio`, the address will normally be:

```text
https://umarhuss2234.github.io/portfolio/
```

The asset links use relative paths, so the website works when it is hosted inside a GitHub project repository.
